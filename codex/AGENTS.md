# 공통 에이전트 지침 (Codex)

- 작업 시작 시, 현재 git 저장소 이름에 해당하는 `~/agent-sync/memory/<저장소명>/MEMORY.md`가
  있으면 먼저 읽고 관련 메모리 파일을 참고할 것. 전역 컨텍스트는
  `~/agent-sync/memory/_global/GLOBAL.md`에 있다.
- 세션에서 오래 기억할 가치가 있는 사실(사용자 피드백, 프로젝트 제약, 반복되는 함정)을
  발견하면 같은 폴더에 `<주제>.md` 파일 하나(사실 하나)로 저장하고 `MEMORY.md`에
  `- [제목](파일명.md) — 한 줄 요약` 형식으로 인덱스를 추가할 것.
